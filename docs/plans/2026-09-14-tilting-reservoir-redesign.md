# 鹿威式双翻斗：视觉与动力学修改方案

状态：用户已批准实施，翻斗、连续角度耦合、双稳态和英文界面已接入。最终按用户新增要求采用 B 面板的 Monostable / Bistable 按钮及顶部 Notes 侧栏。当前行为与验收见 [README](../../README.md) 和 [实施计划](2026-09-14-tilting-reservoir-implementation.md)。下文保留设计阶段论证，其中“候选”“未开放”等表述记录的是实施前状态，备选交互以实际版本为准。

## 1. 结论与范围

采用**带持续慢漏、可移动配重和自动回位机构的教学翻斗**，形态受日式庭院鹿威（shishi-odoshi）启发。它能够以同一种装置表达：

1. 平均输入足够时，慢积水—越过门槛—快倾倒—复位，自行反复发生。
2. 平均输入不足时，储水量在门槛以下达到稳定值；有效进水波动偶尔触发一次倾倒，再返回静息附近。
3. 改变配重或平均输入，可改变事件时刻，也可改变确定性动力学的运行区间。

这次提案有意替换原需求“桶固定、自动阀排水”的表现方式。保留同一引擎驱动两套装置、共享 OU、守恒、固定物理步和真实阈值事件等科学约束。当前网站及其验收结果作为修改基线保留。

不把该装置声称为真实竹筒的完整刚体与流体模拟。一次暂态倾倒不算另一个稳定态；新增双稳态设置须形成真正长期保持的倾倒平衡，见第 12 节。

## 2. 为什么配重需要和慢漏一起出现

若没有任何损失，持续正进水使储水量持续增加；在容量足够且没有先溢出的前提下，任何有限翻转门槛终将被达到。加重配重只能延迟事件，无法单独形成门槛以下的稳定水量。若水先溢出，溢流本身就是另一条损失路径，必须建模，不能当作“重心创造了平衡”。

因此保留清楚可见的小漏水口。在原强排水、倾倒后能完成复位的设置下，未翻转、固定背景、无噪声时：

- 储水量 V 满足 dV/dt = r − kV。
- 无波动平衡储水量 Veq = r/k。
- Veq > Vtip：能自行触发，随后复位并继续循环。
- Veq < Vtip：能停在门槛以下；足够的进水波动可能触发一次事件。
- r(1+a)/k ≤ Vtip：从门槛以下出发，当前有界进水波动本身不足以触发。

配重调整的是 **Vtip**，慢漏决定能否形成 **Veq**。两者是不同的因果环节。

“静息附近偶发爆发”可称为噪声触发的可激发过程。要表达两个长期驻留状态间的随机切换，需增加能保持两种姿态的机械结构，见第 12 节。可通过出水口节流使倾倒态也产生稳定平衡，不能仅给原先必然复位的过程改名。

## 3. 装置构成与可见因果

采用侧前方的正交视角。支点、配重、储水腔与出口都在可见面，主体为竹色/木色框架与透明侧面，不使用不透明整根竹筒遮挡储水。

| 部件 | 用户看到什么 | 对应含义 |
| --- | --- | --- |
| 上方固定供水口 | 水流持续存在，粗细随当前流量变化 | 平均进水与进水波动 |
| 旋转接头/短软管 | 倾倒期间水仍实际送入斗内 | 与持续进水方程一致 |
| 透明储水斗 | 储水体积缓慢增长、快速减少 | 状态变量 V |
| 明确的横向转轴 | 储水斗绕轴倾转 | 翻转装置的机械结构 |
| 可沿杆滑动的配重 | 配重远离支点，储水端更难压下 | 翻转门槛 Vtip 增加 |
| 小漏水口与细流 | 平时一直流出，平衡时可与输入对比 | kV 的持续损失 |
| 低位倾倒出口 | 翻转时敞开，出现明显的大股出水 | 快速释放 |
| 独立低位回位机构 | 储水量降到较低值后开始回位 | 复位条件与滞回 |
| 固定接水盘与外排槽 | 两条出流确实离开系统 | 不暗示水立即循环回当前输入 |

底部快排口采用随倾角开启的教学式出水机构，避免在低储水量下仍从高于水面的杯沿凭空出水。它是鹿威启发的概念装置，不必原样复制真实竹筒。

配重位置必须由门槛统一计算，不能拖配重只改外观。优先用接水姿态下的力矩平衡反解位置：使 V=Vtip 时，水、空斗与配重的合力矩达到设定触发值。先验证可允许范围内该映射单调、且配重始终位于实际支承杆上。

如显示合成重心，使用相同几何和质量定义计算其投影；不另外制作一个与真实触发无关的移动小点。机构存在卡扣力矩时，显示相应限位/锁扣，不能把任意阈值都解释为自由转轴下的重心过轴。

## 4. 推荐的新默认对照

为让“配重决定能否自行触发”直接可见，建议两套装置使用相同的平均进水、慢漏和初态，主要改变配重门槛。

| 参数 | A：较易翻转 | B：较难翻转 |
| --- | ---: | ---: |
| 平均进水 r | 0.144 | 0.144 |
| 慢漏 k | 0.16 | 0.16 |
| 无波动平衡储水量 Veq | 0.90 | 0.90 |
| 翻转门槛 Vtip | 0.75 | 1.00 |
| 随机进水强度 a | 0.00 | 0.90 |
| 初始储水量 V | 0.70 | 0.70 |
| 回位触发储水量 Vreset | 0.12 | 0.12 |
| 完全打开时的快排系数 κ | 8.0 | 8.0 |

A 的平衡储水量位于门槛以上，所以会自行翻转。B 的配重更远，平均进水只够维持 0.90；波动足够时才会越过 1.00。

新 A 在原蓄水方程下首次起倾约 1.80 秒；B 若蓄水阶段、OU 更新和默认 seed 均保持原实现，首次起倾应仍约为 14.22 秒。这里指起倾事件，不能沿用旧快排时长或周期作为新机械模型的保证。全部时间须在实现后重新核验。

动态状态仍根据当前参数生成，不把 A/B 永久命名为振荡器/噪声器。允许通过配重或进水调整交换角色。

## 5. 水量、倾角与动画必须同步

### 5.1 保留与调整

保留：共享 TypeScript 引擎、OU 与 seed 规则、固定 dt=1/120 秒、事件日志、水量账目、显示倍速、页面隐藏处理和静态部署。

调整：原 h 表示直立等截面桶的水位；翻斗中应统一改称**归一化储水量 V**。图中实际水面高度是 V 和倾角的几何结果，不能继续把 V 当作固定高度。

推荐增加一个确定性的倾角状态 θ 及明确的回位阶段，不增加随机力矩、随机摇晃或完整流体求解。双稳态扩展通过调节同一出水系数 κ 完成，见第 12 节。

### 5.2 最小耦合规则

使用概念化方程：

```text
q = r [1 + a tanh(z)]
Qslow = k V
Qfast = κ g(θ) V
V' = q − Qslow − Qfast
```

其中 g(θ) 是教学装置的出水开度：接水姿态为 0，充分倾倒为 1，随实际倾角单调开启。它代表设计过的出水机构，不声称等同于任意开口竹筒的真实水力公式。

```text
ACCUMULATE：保持接水角，g=0。
  V 达到 Vtip → 记录一次起倾事件，进入 POUR。

POUR：确定性地快速转向倾倒角，g 随 θ 开启。
  V 降到 Vreset → 进入 RETURN，不瞬间删除余水。

RETURN：快速回位，g 随 θ 关闭，继续计算所有进出水。
  到达接水角 → 进入 ACCUMULATE。
```

这三个阶段不是三种长期稳定态。在原强排水设置下，POUR 和 RETURN 是一次事件内部的运动阶段；第 12 节的节流设置则允许 POUR 在完成起倾后保持稳定水量与倾角。

倾倒和回位各约 0.10–0.15 个模拟秒作为初始调试目标，最终依赖可读性、守恒与步长收敛检验确定；动画绝不使用墙钟独立计时。1× 下先看整体快动作，0.25× 下可以观察起倾和回位。

Vreset 在新模型中表示“开始回位”的储水量，回位期间仍有进出水，因此回到接水姿态时的 V 不必精确等于 Vreset。页面与 README 需明示这一变化。若要严格保持原固定复位水量语义，则必须采用另一套明确的出水关闭机构，并单独验收，不能两种解释混用。

开度进入方程后，原两常系数状态的解析周期不再直接适用。按固定步对角度与流量耦合积分，在实际阈值处切分步长；对半步长结果做收敛验证。每段流入、慢漏、快排都进入同一账本，不能用截水量弥补误差。

### 5.3 几何和连续性

- 水面在世界坐标中保持水平，不能随整个斗一起刚性转动。
- 给定 V 和 θ，求水平切面与储水腔的交截，使可见水体体积对应 V；先选易计算的棱柱形腔体。
- 出流起点跟随真实出口，向下落入接水盘；细漏始终存在，粗流由 Qfast 驱动。
- 供水必须在全角度范围实际进入斗内。若改用会错过杯口的自由水柱，就必须另建捕获率与旁路流量；推荐旋转供水接头以避免这个额外模型。
- 配重手动调整和自动渐变共用同一参数；在已倾倒阶段改变 Vtip 不会取消本次倾倒。
- 有限转动时间会造成起倾后的短暂继续蓄水；容量检查必须为这段最大可能净流入留余量。不能让加水刚好到 2.00 后又越界，再在绘制时偷偷截断。
- 加水保持真实脉冲、下一物理步执行、每套装置最多一个待执行请求；若需要容量余量，应在禁用提示中明确说明。

## 6. 信息表达重排

主标题：**The tipping point.**
副标题：**Same water. Different dynamics.**
各实验只保留一句英文观察提示，例如 **Turn noise off: which reservoir keeps tipping?**；不再增加并行的项目名或装饰性子标题。

首屏优先顺序：

1. 简短英文标题、一个 Experiment 下拉框、Pause/Resume 与 Noise off。
2. 两套足够大的翻斗，以及紧邻各自装置的动态状态。
3. 紧贴装置的当前储水量、翻转门槛和无波动平衡储水量，避免额外数字卡片。
4. 直接位于装置下方的两幅历史曲线。
5. 默认折叠的 Adjust parameters，其中容纳三个参数和加水。
6. 默认折叠的 About the model，容纳深层解释、公式与参考文献。

相比当前页面，压缩顶栏和实验选择区，减少装饰性留白，把装置提升到主要视觉区域。桌面 1440×900 应同时完整看到两套装置、配重、慢漏和倾倒出口。手机上每套装置的编号、状态和标尺紧邻对应装置；展开参数区后保留醒目的 A/B 编号，避免跨屏时失去对应。

### 三个主控制

- **Mean inflow**：Low—High，旁边显示 r；改变管内流束与平衡储水量。
- **Counterweight**：Easier to tip—Harder to tip，同时显示对应翻转门槛 Vtip；滑块与配重位置同步。保留键盘可操作的原生滑块，直接拖动配重可作为额外交互，不能成为唯一入口。
- **Inflow noise**：Steady—Variable，保留强度与开关记忆。

人工加水按钮收进对应装置的参数区，保留 +0.15 的真实输入含义；展开参数时可在储水口给出一次短暂定位提示。

### 两个关键解释

储水时显示 **Accumulating** 或 **Inflow balances the slow leak**；不要只因为处于 ACCUMULATE 阶段就永远写水量上升。判断增长/减少可用实际净流量，并以适当容差避免数值文字抖动。

到达门槛附近时可显示 **0.XX more water to tip**。不要显示固定倒计时，因为有噪声时下一次事件时刻未知。

高级 **Show balance** 开关可叠加水侧力矩、配重恢复力矩和支点投影。默认只展示必要的支点与配重标签，避免整屏力学箭头。

## 7. 四个引导实验的具体改写

| 实验 | 初态与变化 | 画面应传达 |
| --- | --- | --- |
| A：Steady inflow | 两侧 r=.144、a=0，门槛分别 .75/1.00 | 左边自行翻，右边停在 .90；静息右斗的进水与慢漏接近平衡 |
| B：Random inflow（默认） | 同一组 r/H，B 加 a=.90 | 右斗被有效涨落推过门槛，随后自动倾倒和回位 |
| C：Move the counterweight | 从无噪声对照重载；等 3 秒后，10 秒内将 B 门槛 1.00 降至 .75 | 配重移动和门槛下降同时可见；进入自行循环区间 |
| D：Increase mean inflow | 从无噪声对照重载；等 3 秒后，10 秒内将 B 的 r=.144 增至 .200 | Veq 从 .90 升至 1.25；改变积累条件也能让右斗自行翻 |

C 到终点时两套装置参数相同，但历史水量和相位可以不同；不能为展示“相同”偷偷同步或重置它们。

仍突出“关闭全部波动”这一实时操作：只令 a=0，保留当前储水量、倾角、阶段和历史。它应让使用者亲眼看到左侧仍周期性动作，而右侧完成当前事件后静息。

配重冻结仅停止自动位移；暂停停止整个模拟；加载实验重置初态。三个语义保持区分。

- 正文建议 14–16px，主要数字 18–22px，图内文字至少 12px；关键文本对比度至少 4.5:1，焦点清晰。
- reduced-motion 初始暂停，关闭飞溅和非必要插值；核心状态仍准确可见。2D 后备必须表达同样的翻转、配重和慢漏。

## 10. 验收标准

### 科学和数值

- 同装置、同引擎，仅参数决定工作区间。
- 无噪声高阈值右斗能稳定，而非只是等得更久。
- 配重移动同时改变可见力矩条件与真正的触发阈值。
- 噪声改变输入，不直接安排倾倒事件或推倒支架。
- 事件只在真实起倾处登记一次；回位不产生额外事件。
- 水量、角度、出流、字幕、事件及曲线来自同一输出。
- 所有流量计入守恒；无负水量、假清空或隐藏溢出。
- 同 seed/同操作模拟时刻可重现；帧率和装饰不影响随机轨迹。
- 步长减半后，事件时刻与流量账目收敛；旧解析周期只用于原常系数模型基线。

### 直观性和体验

让首次接触的观察者在不打开公式的情况下，能够回答：

1. 水为什么会积累，又为什么可能不再增加？
2. 哪一部分决定“多重才会翻”？
3. 为什么一次翻转后会自己回来？
4. 关闭波动后，为什么一边仍会翻，另一边可能停下来？

桌面和 360px 手机都看得到慢漏、支点、配重及倾倒出水。1× 能分辨是否正在翻转，0.25× 能看清动作细节。检查边界参数、暂停中改配重、倾倒中关噪声、背景冻结、容量限制、WebGL 丢失和减少动态效果。

## 12. 单稳态、双稳态与振荡：使用同一套方程

### 12.1 最终推荐与已完成的数值验证

推荐继续使用同一套“持续进水、慢漏、倾倒排水、高低门槛”的模型，增加**可调倾倒出口**。配重控制 H，出水口控制 κ。不必另起一套连续双势阱方程，也不必新增机械噪声。

关键调整是放宽原方案的约束 `qMax/(k+κ) < hReset`。原约束刻意保证每次快排必然完成复位，因而排除了排水态的稳定平衡；新双稳态实验需要允许排水与输入在复位线以上平衡。

**低水位复位规则仍然保留。** 若稳定储水量始终高于复位线，就不会触发回位。这比删去规则或用“保持”按钮强行冻结状态更有解释力。

本提案已经通过独立数值验证，见 `tests/bistability-feasibility.test.ts` 的 3 项测试。该文件只检验候选参数；当前页面尚未开放 κ 控件或双稳态模式。

### 12.2 同参数下的两个真正平衡

固定输入、关闭噪声，两个分支分别有：

```text
接水分支：Vfill*  = r / k
倾倒分支：Vdrain* = r / (k + κ)
```

只要同时满足：

```text
Vfill* < H          接水态不会自行触发倾倒
Vdrain* > hReset    倾倒态不会自行达到回位条件
```

就能出现两个不同的长期稳定状态。等价条件为：

```text
(k + κ) hReset < r < k H
```

已验证的示例：

| 参数 | 数值 |
| --- | ---: |
| r | 0.144 |
| k | 0.16 |
| H | 1.00 |
| hReset | 0.12 |
| κ | 0.80 |
| a | 0 |

由此得到 `Vfill*=0.90` 和 `Vdrain*=0.15`。0.90 低于翻转门槛 1.00；0.15 高于回位线 0.12。

从接水分支附近启动，回到 0.90；从倾倒分支附近启动，回到 0.15。两处的微小扰动均衰减，恢复率分别为 k=.16 和 k+κ=.96。新增测试分别运行了不同初态的 150 秒积分，并检验水量守恒。

一次 +0.15 人工加水可以把 0.90 推到 1.05，触发倾倒，随后稳定在 0.15；再将进水短暂减弱至 .06、持续 1 秒，就能降过 .12 并回位。恢复原进水 .144 后，装置重新趋向 .90。这条双向转换路径已通过测试。

### 12.3 用画面区分三个教学情形

| 英文名称 | 固定背景、无噪声后的行为 | 可见过程 |
| --- | --- | --- |
| Monostable, excitable | 最终回到同一个静息储水态 | 有效扰动 → 倾倒 → 水降过回位线 → 自动回来 |
| Bistable | 相同参数下，两种初态可以留在两个不同平衡 | 有效扰动 → 倾倒 → 水量停在回位线以上 → 保持倾倒姿态 |
| Self-sustained oscillation | 无新扰动也持续循环 | 平均输入不断把储水量推过门槛，排水后又能完成复位 |

“单稳态/双稳态”在这里指稳定静息状态的数量；自维持振荡的长期吸引子是极限环，不能把循环中两个动作阶段算成两个稳定态。

对原两阈值约化模型，还可得到完整的严格不等式分区。设 `Qfill=kH`、`Qreset=(k+κ)hReset`：

- r < min(Qfill,Qreset)：仅接水分支的稳定平衡。
- Qreset < r < Qfill：两个稳定平衡共存。
- Qfill < r < Qreset：自行循环。
- r > max(Qfill,Qreset)：仅倾倒分支的稳定平衡。

等号处单独处理渐近趋近和临界条件，不沿用严格不等式结论。

### 12.4 对实体形态的要求

需要一个**能保持倾倒姿态、直到储水量低于回位线才释放的滞回机构**。它可以表现为简单的回位锁或限位结构。不是在代码中暂停装置；倾倒保持期间进水、慢漏和快速出口仍在运行并相互平衡。

还必须让 κ 真实对应**倾倒出口开度**。普通大敞口竹筒若已倾倒，水会直接越过口沿倾泻，不能一边画着敞口倒水，一边凭空把 κ 降到 .8。

因此最终装置应为鹿威启发的半透明教学翻斗，具有挡水结构和受控低位出口。κ=8 时能较快排过回位线；κ=.8 时排水较弱，在持续输入下可保留 .15 的平衡水量。水必须确实保留在腔体中；若出现越口溢流，应计入账目并重新判断双稳态是否仍存在。

过中心弹簧或双位置磁性锁扣可以作为另一种机械实现，但不是本项目的必要数值模型。也不建议为离散滞回模型强画一张没有推导依据的 W 形势能图；使用真实储水量轨迹和两种初态的长期结果更清楚。

### 12.5 仍可只使用原来的进水噪声

对候选 κ=.8、a=.9，允许的进水范围满足：

```text
qMax / k = 1.71 > H=1.00
qMin / (k+κ) = 0.015 < hReset=0.12
```

足够持续的强输入可触发倾倒，足够持续的弱输入可触发复位。因此两个方向都在可达范围内，不需要让噪声同时摇动支架。

新增的 300 秒默认种子测试已观察到两方向的状态转换，并验证守恒。这只是一个可复现候选轨迹，不承诺每个短时间窗都发生转换，也不据此宣称通用的驻留时间分布。

要展示“准稳定状态下的偶发转换”，还需联合调整噪声强度 a、相关时间 τ 和各平衡距门槛的距离，使驻留时间明显长于局部恢复与转换时间。本例两个分支的局部恢复时间约为 6.25 秒和 1.04 秒。用多个固定 seed 的驻留时间验证“偶发”；a=.9 目前只用于验证双向可达性，不能据此宣称已形成稀有转换。任何展示预设都应公开 seed，不插入定时强制翻转。

### 12.6 页面如何加入而不增加杂乱

在同一个 Experiment 下拉框中增加 **One or two resting states** 示例，主界面不新加一排模式按钮。

- 首先关闭噪声，两套装置使用相同 r=.144、H=1、k=.16、hReset=.12，均从接水分支的平衡 V=.90 开始。该示例不沿用普通实验的 V=.70 初态，否则立即加 .15 尚不足以触发 H=1。
- A 使用强排水 κ=8，B 使用节流 κ=.8；实际出口开度同步显示。
- 一个上下文相关的 **Add a pulse** 操作可向两边施加相同 +.15 水量，便于比较“排完回来”和“停在新状态”。它执行真实加水，不直接命令翻转。
- “不同初态是否得到相同结果”的比较放在展开的参数/实验设置中。必须在同一组参数下切换初态，不能用不同 κ 各拍一张图就当作证明。
- κ 默认由预设设置，仅在 Adjust parameters 展开时显示 **Drain opening**。主要演示仍保持少量按钮。
- 当前英文页面先保留原模型范围，明确写出不含双稳态；新模式只有在倾倒几何、开度与稳定分支全部接入后才展示。

### 12.7 实现与验收增量

除前述翻斗文件外，还需扩展参数类型/校验与 `describeRegime`：它不能再只比较 r/k 与 H，必须同时判断 r/(k+κ) 与回位线。实际阶段和长期动力学仍分开显示。

新增验收包括：相同参数下两个稳定平衡、两边的小扰动恢复、跨阈值后的持久切换、双向波动触发的可达性、临界等号情况、保持倾倒期间的守恒，以及移动 H/κ 后旧稳定分支的失稳。

固定倾角的两个分支满足 g=0/1 时，上述平衡结果可保留；有限起倾/回位的暂态会改变事件时刻，仍需在新的角度耦合实现上重新核验。不能把目前三个候选测试当作新 3D 双稳态装置已经实现的证据。
