# The tipping point

英文交互教学网站：用两套鹿威（shishi-odoshi）启发的翻斗，比较自维持慢–快振荡、单稳态可激发事件和双稳态噪声驱动转换。储水量、倾角、出口、曲线及事件来自同一个物理引擎。

使用 Vite + TypeScript + Three.js + 原生 HTML/CSS。几何体与材质在本地生成，运行不依赖 CDN、远程素材、API、登录或后端。


## 页面与操作

主界面只保留 **Random inflow** 这一种实验：A 是稳定进水的自维持振荡参照，B 接收随机波动输入。已移除实验下拉菜单、全局 Noise off 按钮及自动背景变化控件；速度和重放位于 **Controls**，详细参数和真实加水脉冲位于 **Adjust parameters**。

每侧动画右边都有一个竖直 **Tip threshold** 滑条。向上增大 H，并把可见配重向杠杆尾端移；向下降低 H，使翻转更容易。也可直接用鼠标或触摸拖动配重。配重和滑条更新同一个真实参数，立即双向同步；键盘方向键与 Home / End 同样可用。暂停时调整门槛保留水量和姿态，恢复后物理引擎判断是否起倾。

B 面板内的 **Monostable / Bistable** 切换会设置 B 的 `r=.144`、`H=1` 和 `κ=8/.8`。切换保留两边当前水量、倾角、动作阶段、模拟时间、噪声强度和历史。这两个按钮表示的是**出口配置**（宽出口，或节流出口＋挡水唇），因此调整 `r` 或门槛 `H` 时选中状态与挡水唇都保持不变，只有改变出流系数 `κ` 才清除选中；实际动力学始终由状态文字说明，两者不会互相干扰。

右上角 **Notes** 打开侧边栏，集中显示解释、方程、seed、事件记录、科学边界、参考文献和作者信息。支持关闭按钮、Escape、背景点击和键盘焦点恢复。

- **Reset & replay** 恢复默认随机进水实验与当前 seed；更换 seed 重新运行该实验。两边水量恢复到 .70、回到斜置接水姿态、B 恢复单稳态出口并清空历史。重放保留暂停状态和速度。
- 折叠参数区保留各侧噪声开关和强度，便于检验关闭波动后的保持或回位；开关记住此前强度。
- **Add water +0.15** 在下一物理步执行。每边最多一个待执行请求；暂停或蓄水余量不足时禁用。
- 0.25× / 0.5× / 1× / 2× 只改变单位墙钟时间推进的模拟秒数，不改变固定物理步。
- 页面隐藏时停止推进，恢复后不补算隐藏期间的墙钟时间。减少动态效果设置下初始暂停。

## 模型与三种行为

所有储水量、质量和流量使用教学相对单位，模拟秒不映射为气候年份。内部 `TankState.h` 为兼容历史数据结构保留名称，其意义已改为储水体积 **V**，不是倾斜容器的水面高度。

```text
q(t) = r [1 + a tanh(z(t))]
dV/dt = q(t) − kV − κ g(θ)V − Qspill
g(θ) = clamp[(θ − θrest) / (θtip − θrest), 0, 1]
```

`θrest=.40 rad`、`θtip=.65 rad`。θ 表示从接水姿态向下转过的角度，圆筒实际倾角为 `.40−θ`：接水时斜口朝上约 23°，完全倾倒时朝下约 14°。前端出口在筒体越过水平后才开启。完整起倾与回位各需 .15 个模拟秒，角度属于物理状态，动画不另设事件计时器。

```text
FILL：保持接水角；V 到 H → DRAIN，记录一次起倾事件
DRAIN：转向倾倒角；V 到 .12 → RETURN
RETURN：转回接水角，仍计算进出水；角度到零 → FILL
```

回位线 .12 表示开始回位；回位期间仍流出水，完成回位的水量不强制等于 .12。改变高门槛不取消已经开始的倾倒。

| 参数 | A 默认 | B 默认 | B 双稳态按钮 |
| --- | ---: | ---: | ---: |
| 平均进水 r | .144 | .144 | .144 |
| 慢漏 k | .16 | .16 | .16 |
| 倾倒出水系数 κ | 8 | 8 | .8 |
| 翻转门槛 H | .75 | 1 | 1 |
| 回位线 | .12 | .12 | .12 |
| 噪声强度 a | 0 | .9 | 保留当前值 |
| 初始 V | .70 | .70 | 保留当前值 |

可调范围为 r=.06–.30、H=.55–1.65、a=0–.95、κ=.4–8。配重按接水姿态力矩平衡映射 H；可见锁扣提供滞回。改变 κ 会改变真实流量和可见出口开度。

在固定背景、无噪声下，接水分支平衡为 `Vfill=r/k`，完全倾倒分支为 `Vpour=min[r/(k+κ), Vrim]`。完全倾倒时筒口以下可保留约 .294 单位水量；更强输入会产生稳定溢流，其流量为 `r−(k+κ)Vrim`。因为 Vrim 高于回位线 .12，以下条件仍成立。设 `Qfill=kH`、`Qreturn=(k+κ)×.12`：

| 条件（严格不等式） | 长期行为 |
| --- | --- |
| r < min(Qfill,Qreturn) | 仅接水稳定平衡 |
| Qreturn < r < Qfill | 两个稳定平衡共存 |
| Qfill < r < Qreturn | 自维持循环 |
| r > max(Qfill,Qreturn) | 仅倾倒稳定平衡 |

等号属于临界情形，单独处理。动作有接水和倾倒两个阶段，不自动意味着双稳态。

B 双稳态参数对应接水 **.90** 与倾倒 **.15** 两个平衡，分别低于起倾门槛 1 和高于回位线 .12。在接水平衡处加 .15 可以触发并留在倾倒平衡；短暂减弱输入可触发回位。若从默认初态 .70 立即加 .15，则尚未达到门槛，不能保证翻转。

噪声只作用于输入，不随机推倒支架。强输入可推动接水态越过 H，持续弱输入可使倾倒态降过回位线；不是用计时器安排事件。默认波动用于展示可复现的不规则事件与双向可达性，不声称每个短窗口都会切换，或已经校准了稀有事件的驻留时间分布。

## 几何、守恒与历史

外形采用竹质尾段、透明圆柱储水段和真正的斜切开口，接水姿态参照真实鹿威。固定进水口由一根立柱和一根连续弯折的竹质出水管组成：弯折处为圆弧过渡而非对接，出口是真正的空腔，在斜口上方垂直落水；接水与倾倒全过程都校核水线穿过实际开放部分，未使用绕支点的供水管。

斜口下部的透明挡水唇与节流出口，是为展示双稳态而加入的教学结构：普通完全排空的竹筒不能长期保持有储水的倾倒平衡。挡水唇是随**节流出口（κ<4）一起安装**的装置件，从筒口下缘升起，切换时播放约 0.4 秒的升起动画并闪动三次提示注意；它与进水量、门槛设置无关，所以拖动门槛不会让装置突然少掉一块。宽出口配置（自维持循环与单稳态默认值）下筒口保持开口。转动导致开口以下的可储水量缩小时，多出的水从真实最低开放筒口溢出，并计入守恒。它不是完整的刚体或流体仿真。

储水段是完全透明的筒身，体积感由双面玻璃壳自身的叠影、筒口端面与后端竹节环提供，既不画不透明遮挡，也不画筒内的纵母线。筒体上**只标起倾门槛**：一圈暗红虚带加一层极淡红色平面（WebGL 忽略线宽，所以门槛用虚化带面，斜视时由那层极淡平面兜底，不会退化成发丝线）。它把体积按接水姿态换算成水位（与配重、门槛滑条共用 `waterSection` 映射），并随筒体一起转动，所以水位上涨到与门槛带相交就是真实的起倾时刻；回位线与两条平衡水位只保留在图表里。水面另有一圈轮廓线。斜口尖端不加黄铜出水嘴：受控出流本来就从同一个下角流出，额外的管件只增加噪声。挡水唇升起时，提示环跟随其当前大小向外扩散，不会先画出整块轮廓。起倾瞬间门槛带会闪动两次。慢漏从筒底固定的渗水孔滴出。

水体由带斜口的多面圆柱与世界水平面裁切得到，体积与 V 一致。水面不随容器刚性旋转；慢漏固定从筒底靠封闭端最低处的渗水孔滴出，不随水量沿筒底移动，倾倒后该孔露出水面就不再显示滴流（模型中的 `kV` 账目不变）；受控出流从低位出口流出，溢流从开放筒口流出。Three.js、SVG 后备和物理引擎使用同一几何定义。配重位置由接水姿态的水体质心与力矩求得，拖动通过其单调逆映射改变 H。

固定物理步为 `dt=1/120 s`。静止角度阶段使用常系数指数解；转动阶段耦合角度与出水，使用细分积分并分割真实阈值穿越。进水、慢漏、受控出流、筒口溢流和人工脉冲分别记账：

```text
初始水量 + 持续输入 + 人工加水 − 慢漏 − 受控出流 − 筒口溢流 = 当前水量
```

图表保留最近 60 个模拟秒的实际储水量、门槛及当时的平衡分支；淡色阴影表示实际倾倒/回位阶段。倾倒平衡仅在它高于回位线、可以长期保持时额外显示。模式切换不会改写旧曲线。纵轴按整齐步长取刻度并配网格，横轴对齐 15 秒；指针悬停或触摸图表会显示十字线读数（该时刻的 V、当时门槛与模拟时间）；接水平衡与倾倒平衡分别用点线和短划线，起倾点是曲线上的实心圆。门槛滑条固定在各自半区的右侧栏，不随装置转动而移动，也不与装置重叠。

OU 相关时间为 `τ=1.2 s`，默认 seed 为 `20260914`；每个固定步精确更新一次 OU，使用 Mulberry32 和 Box–Muller cosine 分量。两边共享 z；相同强度时相对流量波动一致。视觉和帧率不消耗随机数。同 seed、初态、参数和同一模拟时刻的操作序列可重放。

几何校核得到接水姿态的筒口以下容量约 **2.094**，完全倾倒时约 **.294**；固定垂直水线在完整角度范围内进入挡水唇上方的开放斜口。默认 A 首次起倾约 **1.798 秒**，稳定周期约 **10.776 秒**，B 首次起倾约 **14.222 秒**。B 从初始时刻选择双稳态，在 15 秒禁用 B 的噪声，25 秒时保持倾倒，水量约 **.150009**。这些是模型积分的结果，并非动画预设时刻。

常见问题：

- **构建报 Node 版本不符或依赖引擎错误**：查看构建日志开头打印的 Node 版本。Pages v3 构建镜像默认 Node 22.16.0，且**不会**从 `package.json` 的 `engines` 推断版本；请确认上面的 `NODE_VERSION` 已设置，或确认仓库根目录存在 `.nvmrc`（两者本项目都指向 `24.14.0`，结果一致）。
- **部署成功但访问是 404**：确认构建输出目录拼写为 `dist`，且构建产物含 `index.html`；本项目无客户端路由，不需要 `_redirects`。
- **想用子路径部署**（例如 `example.com/demo/`）：把 `vite.config.ts` 的 `base` 改成对应前缀后重新部署，根路径部署保持 `/`。

Pages 按构建命令生成并托管静态输出，根目录未指定时使用仓库根。[Cloudflare Pages 构建配置](https://developers.cloudflare.com/pages/configuration/build-configuration/) · [构建镜像与 Node 版本](https://developers.cloudflare.com/pages/configuration/build-image/)
